Acerca del módulo

Consulta y seguimiento de cotizaciones en un solo lugar. Desde aquí accedes al listado principal y, cuando corresponda, a otras acciones del flujo de negocio.

Qué puedes hacer

  • Ver el listado de cotizaciones con sus estados.
  • Reintentar la carga si la conexión o el servicio fallan.
  • Identificar cuando no hay registros y no hay error.

Si necesitas ayuda con un caso concreto, contacta a tu equipo de soporte o administración.
