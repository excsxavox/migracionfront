# Discrepancias — código ↔ reglas ↔ specs

Añadir aquí un fichero Markdown por hallazgo persistente cuando no se pueda resolver en el mismo commit.

## Convención sugerida de nombre

`YYYY-MM-DD-<slug>.md` (kebab-case).

## Contenido mínimo

- **Hallazgo:** qué diverge.
- **Evidencia:** rutas de fichero, captura o pasos de reproducción.
- **Spec afectado:** p. ej. `openspec/specs/frontend-shell/spec.md`.
- **Regla afectada:** p. ej. `.cursor/rules/testing.mdc`.
- **Severidad:** bloqueante / mayor / menor.
- **Acción propuesta:** actualizar spec, regla o código; responsable sugerido.
